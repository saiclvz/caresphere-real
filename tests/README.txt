Synthetic-specimen tests for the ID scan (no real IDs). gen.py draws the specimens; run.js scans each one; sum.js runs the front+back scenarios; accuracy.js scores OCR; adapters.js covers adapters offline and PhilSys Check. They were run in the build workspace (paths at the top of each file point there) with the Tesseract command-line engine. Results: accuracy.txt, sum-results.txt, adapters-results.json.
